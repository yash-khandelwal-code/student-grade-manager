============================================
  Student Grade Management System
  Unit 5 Project - Python Programming
============================================

HOW TO RUN:
-----------
Just run:   python main.py

REQUIREMENTS:
-------------
- Python 3.x
- tkinter  (comes with python by default)
- turtle   (comes with python by default)

No need to install anything extra!

FEATURES:
----------
1. Add students with marks for 5 subjects
2. Calculates average and gives grade (A+/A/B/C/F)
3. Shows all students in a list
4. Click on a student to see their marks
5. Bar chart using TURTLE module (Unit 5)
6. Remove any student
7. Find class topper

UNIT 5 CONCEPTS USED:
----------------------
- Turtle module: drawing bar chart (turtle.Turtle, fillcolor, begin_fill, end_fill, goto, write)
- Tkinter module: GUI window, Labels, Entry, Button, Listbox, Frame, messagebox
- Widgets used: tk.Label, tk.Entry, tk.Button, tk.Listbox, tk.Frame, tk.Scrollbar

GRADING SCALE:
--------------
A+  ->  90 and above
A   ->  75 - 89
B   ->  60 - 74
C   ->  45 - 59
F   ->  below 45

NOTE: The turtle chart opens in a new window.
      Close that window to come back to the main app.
